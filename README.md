# RAG自动化评测问答系统
秋招简历项目：集成RAG私有知识库 + AI自动化评测工具
## 技术栈
Python、FastAPI、Requests、Pytest、LangChain、Chroma
## 功能说明
1. 批量清洗标注数据集脚本（适配数据标注工作）
2. 接口自动化批量调用大模型API
3. RAG PDF文档私有问答知识库
4. 自动统计模型幻觉率、召回率，生成可视化测试报告
## 环境准备
1. 安装Python3.9及以上版本
2. 安装项目依赖包
## 运行步骤
1. 执行数据清洗脚本处理标注文本
2. 启动FastAPI后端知识库服务
3. 运行pytest自动化评测脚本，输出Allure测试报告
## 项目用途
用于秋招投递AI自动化测试、RAG应用开发岗位，完整代码每日同步GitHub，具备规范Git提交记录。
